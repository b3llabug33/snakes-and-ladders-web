# Snakes and Ladders (Web)

Browser port of my [console Snakes and Ladders game](https://github.com/b3llabug33/snakes-and-ladders-java), with an actual visual board instead of console text. Same board layout, same snakes/ladders, same rules.

## Running it

Just open `index.html`. No build step, no dependencies.

## Files

- `index.html` — mode select + game screen
- `style.css` — board grid and styling
- `game.js` — game logic, ported from `GameLogic.java`/`ComputerPlayer.java`, plus the board rendering
